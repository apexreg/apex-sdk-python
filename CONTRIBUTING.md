# Contributing to Apex SDK (Python)

Thanks for contributing! This guide explains how to contribute to the Apex SDK for ApexRegistry.

## How to contribute
1. Fork this repository.
2. Create a branch: `git checkout -b feat/your-feature-name`.
3. Make your changes (client, resolver, integrations, examples).
4. Test locally against a running ApexRegistry API (or mock).
5. Open a Pull Request (PR) with a clear description of your changes.

## Code style
- Use clear, simple Python 3.9+ code.
- Keep functions small and focused.
- Add docstrings to public functions.
- Provide example snippets in examples/ for new features.

## Testing
- Add tests for client and resolver logic if applicable.
- Ensure LangChain and CrewAI adapters return the expected structure.
